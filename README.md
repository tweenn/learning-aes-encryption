# learning-aes-encryption
A quick repo to test AES encryption in back/front ends

## Getting Started
On `pnpm start` you generate the github pages dataset.json with all data over JWT, AES and LZW;

On `pnpm watch` you get a blank html5 page that console.log the fully decrpted and decoded `LZW Encripted LZW` value of the above report.

On `pnpm run docs` you get the github-pages running locally.
